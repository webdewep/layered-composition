Многослойная композиция: инлайн SVG на фоне, фотокарточки внахлёст и крупный заголовок поверх. При ховере карточка выходит на передний план, остальной контент затемняется. Адаптив реализован через container queries — брейкпоинты привязаны к ширине контейнера, а не viewport. Три режима вёрстки: абсолютное наложение (десктоп), сетка 2×2 (планшет), горизонтальная прокрутка (мобила).
